Import Data ke Aplikasi Catatan Perkuliahan

Petunjuk Penggunaan:
  1. Salin isi dari file lecture_notes_db.json Anda
  2. Tempelkan di kotak teks di bawah ini

Catatan: Data akan disimpan secara lokal di browser Anda.
